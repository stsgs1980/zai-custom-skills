# Как пользоваться

## Команды для агента

| Что нужно | Команда |
|-----------|---------|
| Извлечь из текущего проекта | "извлеки компоненты в ui-kit" |
| Извлечь из репо | "извлеки компоненты из https://github.com/user/project" |

## Workflow

```
1. Агент сканирует проект на UI паттерны
2. Выбираете что извлечь
3. Компоненты добавляются в @stsgs/ui
```

## Важно

| Правило | Почему |
|---------|--------|
| Исходный проект НЕ меняется | Только читаем |
| Цвета параметризуются | amber -> variant |
| Anti-monolith: <=150 строк | Разбиваем |
